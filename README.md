# HafiCare

HafiCare is an AI-powered health assistant that helps users find doctors, analyze symptoms, book appointments, and manage their health information. The project is currently **in active development**, and features will continue to evolve.

---

## Features (In Progress)

- AI symptom analysis  
- Doctor search & recommendations  
- Appointment booking (planned)  
- Medical notes & health record management  
- Modular and expandable architecture  

---

## Tech Stack

- **Python**
- **Pydantic** 
- **Neo4j / Graph DB** (planned integration)  
- **LLM/AI components** for symptom analysis and suggestions
